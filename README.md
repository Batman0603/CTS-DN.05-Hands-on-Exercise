# CTS - Digital Nurture 5.0 Training Program

This folder contains all the hands-on exercises and projects from the **Digital Nurture 5.0** training program, organized by week and topic.

## Folder Structure

### Week 1: Core Concepts & Design Patterns
- **Data Structures and Algorithm**: Search algorithms (Linear, Binary), E-Commerce search implementation, Employee management, Financial forecasting
- **Design Patterns and Principles**: Singleton pattern, Factory method pattern with document implementations
- **PL-SQL**: SQL exercises covering fundamental database concepts
- **SLF4J**: Logging demonstrations with SLF4J framework
- **TDD using JUnit5 and Mockito**: Unit testing fundamentals and mocking strategies

### Week 2: Spring Framework & Persistence
- **Spring Core Maven**: Library management system with Maven and Spring Core dependency injection
- **Spring Data JPA with Spring Boot, Hibernate**: ORM setup and entity management exercises
- Exercises covering basic CRUD operations and database persistence

### Week 3: RESTful Web Services
- **Spring REST using Spring Boot 3**: Building RESTful APIs with modern Spring Boot architecture
- Multiple exercise outputs demonstrating REST endpoint development

### Week 4: Microservices Architecture
- **Microservices with API gateway**: 
  - Account microservice
  - Loan microservice
  - API Gateway implementation
- Each service includes full Maven setup with Spring Boot

### Week 5: Frontend Development with Angular
- **Angular_HandsOn**: Full Angular application (`student-course-portal`)
  - Standalone components
  - NgRx state management (course and enrollment features)
  - Angular routing and HTTP client
  - Unit testing with Jasmine and Karma
  - Component lifecycle and form handling
  - Interceptors and guards for authentication

### Additional Content
- **Output folders** in Week 3, 4, and 5 containing exercise results and demonstrations

## Getting Started

1. Navigate to the specific week folder
2. Explore the exercise subfolders for implementation details
3. Review the source code and accompanying documentation
4. Check the `Output` folders for execution results and expected outcomes
